Publication publique
Le dossier est prêt pour un déploiement statique sur Vercel : vercel.json ajoute des en-têtes de sécurité et un cache léger, et robots.txt autorise les moteurs de recherche à explorer le site. Après publication, Vercel fournit une adresse publique en HTTPS et diffuse les fichiers via son réseau CDN mondial. Vous pourrez ensuite relier un domaine personnel.
Pour publier, importez ce dossier dans un compte Vercel ou reliez-le à un dépôt GitHub puis créez un nouveau projet Vercel. Ne mettez pas CV33.jpg ni le PDF en ligne tant que vous n’êtes pas prête à les rendre accessibles publiquement.
